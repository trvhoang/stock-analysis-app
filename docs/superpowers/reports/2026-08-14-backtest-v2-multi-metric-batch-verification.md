# Backtest V2 Multi-Metric Candidates and Batch Verification

Date: 2026-08-14

## Delivered

- Certified artifacts use schema version 2 and contain one ordered candidate
  list. A candidate records every certification metric won by the exact same
  immutable indicator combination.
- V1 artifact readers are rejected; they are neither converted nor replayed.
  Existing position-history readers retain only their frozen legacy scalar
  snapshots.
- Collect Signals accepts one to five unique, comma/space-separated tickers,
  processes them sequentially, and exposes one automatically-polled batch job.
  The themed path shares one VN-Index preflight, keeps no-theme then themed
  output order per ticker, and retries ticker failures once after the first
  pass. A terminal ticker failure is recorded without failing sibling tickers.
- The page renders grouped metric labels and per-ticker attempts/state/errors.
  Current Positions saved-set creation forwards the complete V2 metric group
  into its frozen reference.
